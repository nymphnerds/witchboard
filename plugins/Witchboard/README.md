# Witchboard

| Plug-in | GUID | What it does | Release file |
| --- | --- | --- | --- |
| Witchboard | `WtC1` | Routing mixer and serial patchbay for the disting NT | `Witchboard.o` |

Witchboard is a C++ plugin for the Expert Sleepers disting NT. It exposes normal
NT parameters for channel gain, two four-state insert selectors, FX send mixes,
and final output routing.

The plugin does not parse MIDI itself. MIDI mapping is handled by the disting
NT's native MIDI Mapping system.
